# 页相随 PageAlong 安卓应用设计

日期：2026-08-27

## 1. 目标

为页相随 PageAlong 增加一个 **Android-only** 的原生应用端，技术栈使用 **React Native + Expo**，并尽量复用现有 Web 端后端接口。

这个应用不是把 Web 页面简单套壳，而是一个面向手机学习场景的阅读和听读入口，核心目标是：

- 进入路径短。
- 阅读表面干净。
- 播放不中断。
- 导入和下载状态可追踪。
- 课程、系列、标签、任务这些数据模型和 Web 端保持一致。

### 1.1 视觉参考

- app 的设计、交互、组件、文字风格参考 `/Users/jqsf/Downloads/cubox` 目录里的竞品截图。
- 借用的是界面语法，不是品牌元素：深色底、强留白、超大标题、紧凑列表/卡片、分段筛选、底部抽屉、图标优先、低噪文案。
- 这套语言要服务阅读和管理，不要做成营销页，也不要做成重装饰的消费级内容流。

## 2. 已锁定决策

- 只做 Android，不做 iOS。
- 不做 `Sign in with Apple`。
- 不做手机短信验证码登录。
- 微信登录保留，但仅在国内用户可见。
- 手机一键登录保留为可选能力，前提是没有直接金钱成本且接入路径明确。
- 主题只保留白天和夜间两种，不做动态色或额外主题。
- 后端接口优先复用 Web 端现有接口，只有确实无法复用时才补新接口。
- 播放器在应用切到后台后不能停止。
- 下载逻辑要和 Web 端一致：文件已准备好就立即下载，未准备好就提示生成中并引导去任务页。

## 3. 不在首版范围内

- iOS 发布。
- Apple 登录。
- 短信验证码登录。
- 支付、订阅、广告。
- OCR、真实 TTS、推荐、生产级可观测性。
- 完整离线同步。
- 需要额外商业 SDK 才能成立的功能，除非后续单独立项。

## 4. Spec 划分

### Spec 1: Android 基础底座

范围：

- 应用启动、路由骨架、底部 4 Tab、顶部栏骨架。
- 登录态持久化。
- 统一 API 客户端。
- 白天/夜间主题切换。
- 后台音频播放底座。

目标：

- 应用能启动。
- 登录态重启后仍然可恢复。
- 所有请求带上 bearer token。
- 播放器切到后台不会停。

### Spec 2: 启动页与登录

范围：

- APP 加载页。
- 登录页。
- 协议勾选。
- 邮箱密码登录。
- 邮箱验证码登录。
- 微信登录入口。
- 手机一键登录入口。
- 登录/注册一体化流程。

新增后端能力：

- 登录能力查询接口，用于返回当前用户/IP 可见的登录方式。
- 微信登录 token/code 交换接口。
- 手机一键登录 token 交换接口。

目标：

- 未登录用户只能看到登录流程。
- 国内用户能看到微信登录。
- 如果一键登录不可用，邮箱登录仍然完整可用。
- 登录态长期保存。

### Spec 3: App 壳与全局入口

范围：

- 默认顶部栏。
- 左侧搜索组件。
- 右侧导入组件。
- 底部 4 Tab：工作台、课程库、下载资源、我的。
- 搜索遮罩层。
- 全局返回和手势行为。

目标：

- 搜索入口短。
- 导入入口短。
- 不把主入口藏得很深。
- 搜索只按标题查用户已收藏内容。

### Spec 4: 工作台与课程库

范围：

- 工作台首屏的继续学习卡片。
- 最近阅读课程列表。
- 课程库页。
- 系列课程页。
- 分页、排序、筛选、星标、多选、批量操作。

目标：

- 工作台只保留轻量统计和最重要的继续学习入口。
- 课程列表用紧凑行，不做大卡片堆。
- 系列课程与碎片课程保持和 Web 一致的数据语义。

### Spec 5: 阅读页与播放器

范围：

- Markdown/正文阅读。
- 目录。
- 系列目录。
- 当前句高亮。
- 悬浮随行播放器。
- 全屏播放器。
- 播放进度保存。

目标：

- 正文是主表面。
- 当前句只做柔和强调，不抢内容。
- 点击句子跳转音频位置。
- 播放器可以从悬浮态展开到全屏，再收回。

### Spec 6: 导入与任务中心

范围：

- URL 导入。
- 页面内 WebView 浏览。
- 收藏触发网页剪藏。
- 文本导入底部弹层。
- 文件导入系统选择器。
- 导入/下载任务列表。
- 失败原因和重试入口。

目标：

- URL、文本、文件三条导入路径都能接到现有后端流程。
- 下载和导入都统一落到任务中心。
- 任务状态清晰可追踪。

### Spec 7: 我的

范围：

- 头像和账号信息。
- 阅读偏好。
- 界面语言。
- 主题。
- 反馈。
- 隐私/条款。
- 退出登录。

目标：

- 个人设置集中收口。
- 和 Web 端的账号体系、主题体系保持一致。

### Spec 8: 分享收藏与导入直达

范围：

- Android 系统分享接收。
- 分享处理中转页。
- 分享后自动进入 URL 导入流程。
- 正文解析完成后自动跳转课程阅读页。
- 音频继续后台异步生成。

目标：

- 其他 App 分享网页到 PageAlong 后，用户无需再手动复制粘贴。
- 课程正文先落库，再跳转到阅读页。
- 音频生成不阻塞阅读。
- 分享入口独立于导入页和下载任务页。

## 5. 关键交互

### 顶部栏

- 左侧是搜索图标，进入遮罩搜索。
- 右侧是加号图标，进入导入页。
- 设计上保持轻，不做重型导航。

### 搜索

- 只查标题。
- 结果只展示课程列表。
- 点击 item 直接进入课程阅读页。

### 导入

- URL：打开 App 内 WebView 供浏览。
- 收藏：抓取当前网页内容，走现有 URL 导入流程。
- 文本：底部弹出文本框和完成按钮，提交后走现有文本导入流程。
- 文件：调用系统文件选择器，上传后走现有文件导入流程。

### 阅读

- 正文直接渲染。
- 当前句用柔和琥珀高亮和左侧细线标记。
- 滚动/触屏时顶部栏、底部栏、播放器可收起。
- 再次触屏或上滑后恢复。

### 播放

- 悬浮播放器是默认收听入口。
- 点击后展开为全屏播放器。
- 后台播放保持继续。

## 6. 后端复用矩阵

### 直接复用 Web 端现有接口

- `POST /auth/email/code`
- `POST /auth/register`
- `POST /auth/login`
- `GET /auth/me`
- `GET /auth/me/preferences`
- `PUT /auth/me/preferences`
- `POST /auth/logout`
- `POST /auth/logout-all`
- `GET /courses`
- `GET /courses/series`
- `GET /courses/{course_id}`
- `PUT /courses/{course_id}/progress`
- `GET /courses/tags`
- `POST /courses/import-url`
- `POST /courses/import-url/extension-sync`
- `POST /courses/import-files`
- `GET /courses/file-import-batches/{batch_id}`
- `POST /courses/{course_id}/audio-generation`
- `POST /courses/{course_id}/downloads/{format}`
- `GET /jobs`
- `GET /jobs/{job_id}`

### 需要补的新接口

- 登录能力查询接口，用来告诉客户端当前登录方式是否可用。
- 微信登录 token/code 交换接口。
- 手机一键登录 token 交换接口。

这三类接口只补最小闭环，不重做账号体系。

## 7. 交付顺序

1. Android 基础底座。
2. 启动页与登录。
3. App 壳与全局入口。
4. 工作台与课程库。
5. 阅读页与播放器。
6. 导入与任务中心。
7. 我的。

## 8. 需要后续单独确认的点

- 首发分发渠道是 Google Play、国内应用市场，还是先做 APK 内测。
- 手机一键登录最终选哪家服务商。
- 文件导入是否要把“文件夹”也纳入 Android 首版。
- 导入页里的 WebView 剪藏，首版是抓页面 title + URL 还是额外做 DOM 级内容提取。
