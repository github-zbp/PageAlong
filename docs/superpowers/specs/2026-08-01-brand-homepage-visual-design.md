# PageAlong Brand Homepage Visual Design

日期：2026-08-01

## 背景

页相随 PageAlong 需要一个公开品牌官网，用来让新用户快速理解产品提供什么服务、是否适合自己，以及当前可以免费试用。官网后续还会做 SEO 优化，因此首屏和页面结构需要直接表达产品类别、核心差异和使用场景。

本设计只定义官网视觉结构和页面叙事，不进入代码实现。

## 已确认方向

官网定位：

```text
可生成音频课程并下载的碎片化阅读器
```

核心解释：

- 普通阅读器解决“看”，但离开屏幕后学习容易中断。
- 音频 App 解决“听”，但主要提供平台已有的体系化课程，不解决用户自己收藏的网页文章、个人博客和课程笔记。
- 剪藏插件解决“存”，但存完之后还是要用户自己找时间读。
- PageAlong 要补上中间缺失的一步：把自己收藏的碎片内容变成可听、可续播、可下载的音频课程。

整体视觉气质：

- 偏音频产品，而不是后台控制台。
- 偏个人学习库，而不是内容平台。
- 简洁、有设计感，但不做通用 AI 风格、大面积渐变或抽象装饰。
- 中文优先，语言直接，让用户不用解释也知道产品是否适合自己。

## 产品边界

官网文案和视觉状态必须遵守当前能力边界：

- 不把真实 TTS 描述成已经稳定上线，除非发布时能力已经完成。
- 不暗示 URL 导入、文件上传、OCR、认证、支付等尚未完成的能力已经可用。
- 可以把“生成后可下载”作为目标定位和上线版本主承诺，但实现前文案需要使用受控表达，例如“生成后支持下载保存”或“免费试用当前可用能力”。
- 免费试用可以作为首屏主 CTA，但不应暗示已经存在完整付费体系。

## 视觉系统

沿用当前产品的安静阅读器基底，并强化音频和下载心智。

### 色彩

- 暖白背景：`#F7F2E8`
- 纸面内容：`#FFFDF8`
- 主文字：`#1F1A14`
- 次级文字：`#70685E`
- 细线：`#DDD2C1`
- 品牌深绿：`#2F6F5E`
- 播放琥珀：`#C98A2E`
- 时间轨浅色：`#F4E6CA`

深绿用于主 CTA、主要控制和品牌可信感。琥珀只用于播放状态、进度条、当前句高亮和少量下载提示，不大面积铺色。

### 排版

- 首屏 H1 需要足够直接，优先使用大号中文无衬线或系统中文字体，字重稳定，不使用夸张字形。
- 正文文案保持短句，避免营销腔。
- 功能标签、进度时间、倍速、下载类型等信息使用紧凑 UI 字号，强化“这是一个可用产品”的感觉。
- 不使用负字距，不用随视口宽度缩放字体。

### 签名元素

签名元素为“内容变声轨”：

- 从碎片内容列表出发，连接到正在播放的文章课程。
- 视觉上像一条安静的时间线，不是夸张音频波形。
- 在首屏、生成流程和产品展示区重复出现，形成品牌记忆。
- 语义上表达“文字内容变成可听的时间”。

## 页面结构

### 1. 首屏

首屏目标：让用户 5 秒内知道 PageAlong 是一个可生成音频课程并下载的碎片化阅读器。

桌面布局：

```text
顶部导航
页相随 PageAlong        适合谁  产品区别  怎么生成  免费试用

左侧
可生成音频课程并下载的
碎片化阅读器

把网页文章、博客干货、课程笔记变成可续播的音频课程。
通勤、做饭、睡前都能继续听，生成后还能下载保存。

[ 免费试用 ]  [ 看看适不适合我 ]

右侧产品场景
课程库中的碎片内容
  技术博客 / 课程笔记 / 长文
        ↓ 内容变声轨
正在播放的音频课程
  当前句高亮
  08:42 / 24:18
  1.25x
  下载音频 / 下载文稿
```

设计要求：

- 右侧视觉不能只是静态截图堆叠，而要表达“碎片内容 -> 音频课程 -> 下载保存”的连续场景。
- 下载入口需要露出，但视觉权重低于“免费试用”。
- 首屏不要使用抽象 AI 插画、装饰光球或通用渐变背景。
- 首屏底部要露出下一屏内容的开头，让页面不是封闭海报。

### 2. 产品区别

目标：解释为什么 PageAlong 不是普通阅读器、音频 App 或剪藏插件。

结构：

```text
为什么不是普通阅读器、音频 App 或剪藏插件？

阅读器
适合认真看，但离开屏幕就中断。

音频 App
适合听体系化课程，但内容不是你自己收藏的。

剪藏插件
适合保存网页，但保存后还是要自己读。

PageAlong
把你收藏的碎片内容生成音频课程，还能续播和下载。
```

设计要求：

- 使用横向对照条或分区矩阵，不做厚重后台表格。
- 前三类工具用低对比呈现，PageAlong 使用深绿和琥珀连接到“缺失的一步”。
- 避免贬低竞品，重点表达适用边界和 PageAlong 补上的能力。

### 3. 场景共情

目标：用接地气场景帮助用户对号入座。

推荐场景：

- 通勤路上：昨天收藏的博客，今天路上听完。
- 做饭收拾时：手上忙着，耳朵还能复习课程笔记。
- 睡前眼睛累了：不再硬撑着看屏幕，切到听完最后一段。
- 碎片时间补内容：不需要一整块时间，也能消化一篇长文。

设计要求：

- 每个场景配小型播放状态，如标题、进度、倍速、当前句。
- 不使用纯图标卡片作为主要表达。
- 场景文案必须像真实用户语言，避免“提升学习效率”这类空泛说法。

### 4. 生成流程

目标：降低用户对“怎么从文章变成音频课程”的理解成本。

流程：

```text
粘贴或导入内容
整理成课程记录
生成句子时间轴和音频
续播、复听、下载保存
```

设计要求：

- 使用“内容变声轨”作为流程主线。
- 只有确实按顺序发生的内容才使用编号。
- 如果上线时真实音频能力仍处于测试阶段，文案需要改为“进入音频生成流程”或“生成完成后”。

### 5. 产品展示

目标：证明这不是概念页，而是有实际产品形态。

展示三个界面片段：

- 课程库：把碎片文章、博客和笔记集中管理。
- 播放页：当前句跟随高亮，像听课一样跟着走。
- 下载区：生成后下载音频或文稿，方便保存和复习。

设计要求：

- 使用真实或拟真的产品 UI。
- 保持界面细节可信，例如状态、字数、句子、播放进度、倍速、下载类型。
- 不展示尚未实现的可用态按钮；未来能力可以在次级区域标注“即将支持”。

### 6. 收尾 CTA

目标：让用户从一个低门槛动作开始免费试用。

结构：

```text
先把一篇读不完的文章，变成可以听的课程

不用先整理完整学习计划。找一篇你最近收藏但一直没读完的内容，
试试看它能不能变成你的下一节音频课程。

[ 免费试用 ]
```

设计要求：

- 收尾 CTA 保持简单，不引入复杂价格说明。
- 免费试用是唯一主动作。
- 可以提供次级链接进入产品详情或常见问题，但不能分散 CTA。

## 响应式结构

移动端首屏顺序：

```text
品牌 + 免费试用
H1
副文案
CTA
手机播放器场景
三条差异化短句
```

移动端规则：

- 不把产品区别压成四列表格，改成纵向分段。
- 首屏产品视觉优先展示手机播放器，不展示复杂桌面截图。
- CTA 保持可点击尺寸，避免文案换行后挤压按钮。
- 页面底部不使用固定营销条，避免和未来播放器心智冲突。

## 导航

推荐顶部导航：

- 适合谁
- 产品区别
- 怎么生成
- 免费试用

导航保持轻量，不需要在首版官网放“价格”“博客”“文档”等入口。SEO 阶段可以再扩展内容入口。

## 参考风格

本轮调研参考了以下方向：

- Readwise Reader：严肃阅读工作流和资料库心智。
- Matter：收藏阅读工具的清晰价值表达。
- Audible、Pocket Casts、Overcast：音频产品的续播、进度和收听场景。
- Linear、Notion、Apple：克制、高层级、产品本体露出。
- Calm、Headspace：生活场景和用户状态表达。
- 微信读书、得到、喜马拉雅、豆瓣阅读：中文内容消费产品的直接表达方式。
